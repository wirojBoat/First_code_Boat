Breathing / Pulse Effect ด้วย CSS

เอฟเฟกต์การหายใจหรือชีพจรสามารถสร้างได้ด้วย CSS animation โดยใช้ keyframes ในการควบคุมการขยายและหดตัวขององค์ประกอบ

1. พัลส์พื้นฐาน

การขยายและหดตัวอย่างนุ่มนวลในวงจรไม่สิ้นสุด

ใช้ animation: breathe1 3s infinite ease-in-out;

2. พัลส์กับเงา

เพิ่มเอฟเฟกต์เงาให้ดูมีมิติมากขึ้น

ปรับขนาดและเงาพร้อมกันใน animation

3. การหายใจช้าๆ

เปลี่ยนความโปร่งใสพร้อมกับขนาด

วงจร 5 วินาที ช้าและสงบ

4. พัลส์คู่

ขยายสองครั้งในหนึ่งวงจร

ใช้ keyframes 3 จุดสำหรับเอฟเฟกต์พิเศษ

5. จังหวะหัวใจ

เลียนแบบการเต้นของหัวใจ

สั้นและกระชับเหมือนจังหวะการเต้นหัวใจ

6. พัลส์เรืองแสง

เพิ่มเอฟเฟกต์แสงเรืองรอบวัตถุ

ใช้ alternate animation สำหรับเอฟเฟกต์ต่อเนื่อง

โค้ด CSS สำหรับ Breathing Effect

/* Breathing Effect 1: Simple Pulse */
.breathing-element {
  animation: breathe 3s infinite ease-in-out;
}

@keyframes breathe {
  0%, 100% {
    transform: scale(1);
  }
  50% {
    transform: scale(1.1);
  }
}

/* Breathing Effect 2: Pulse with Shadow */
@keyframes breatheWithShadow {
  0%, 100% {
    transform: scale(1);
    box-shadow: 0 0 10px rgba(255, 107, 107, 0.7);
  }
  50% {
    transform: scale(1.15);
    box-shadow: 0 0 25px rgba(255, 107, 107, 0.9);
  }
}

/* Breathing Effect 3: Heartbeat */
@keyframes heartbeat {
  0%, 100% { transform: scale(1); }
  10% { transform: scale(1.1); }
  20% { transform: scale(1); }
  30% { transform: scale(1.15); }
  40% { transform: scale(1); }
}
